# Fonts

Two variable-weight latin subsets, embedded in the binary and served from
`/fonts/*.woff2`, so the GUI renders the same on a machine with no decent UI
typeface installed (the fallback was DejaVu Sans, which is why it looked like a
1998 dialog box).

| File | Family | Weights | Source |
| --- | --- | --- | --- |
| `inter.woff2` | Inter | 400–700 (variable) | Google Fonts, Inter v20 latin subset |
| `jetbrains-mono.woff2` | JetBrains Mono | 400–600 (variable) | Google Fonts, JetBrains Mono v24 latin subset |

Both are licensed under the SIL Open Font License 1.1 (`OFL.txt`), which permits
bundling and redistribution with the license attached.
